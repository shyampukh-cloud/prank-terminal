# prank-terminal
Orbit Pay 🛰️ — пранк-терминал
Приложение-розыгрыш для iOS и Android: имитирует экран платёжного терминала с анимациями «оплаты» картой, улыбкой или QR-кодом. В финале друг получает шутку.

Это не платёжное приложение. Деньги не списываются. На экране всегда написано «пранк-терминал, не настоящий», а каждый финал заканчивается пометкой, что это розыгрыш.

Возможности
Три способа «оплаты»: карта (NFC-анимация), улыбка, QR (настоящий случайный QR-код, обновляется каждые 4 секунды).
Анимации: заставка, сканирование, «Передаю запрос…», «Жду ответа…», кольцо с суммой, вспышка в финале.
Два финала: шутка или «ошибка» (кольцо зависает на полпути и краснеет).
Настройки: сумма с пробелами между разрядами («1 500 ₽»), валюта (₽ $ € ₸ ₴ Br), темы, звук, вибрация, скорость анимации, пауза перед финалом.
Скрытые «служебные» экраны: перезагрузка, обновление ПО, нет связи.
Управление
Жест	Что делает
Тап по экрану	запускает «оплату»
5 быстрых тапов по названию «Orbit Pay»	открывает настройки
Свайп влево / вправо	меняет способ оплаты (карта → улыбка → QR)
Тап по нижней части экрана: слева / по центру / справа	«перезагрузка» / «обновление ПО» / «нет связи»
Установка
Android
Скачай OrbitPay-debug.apk из релизов.
Разреши установку из неизвестных источников и открой файл.
iOS
Приложение не опубликовано в App Store, ставится самостоятельно:

AltStore / Sideloadly: подпиши неподписанную OrbitPay-unsigned.ipa своим Apple ID (бесплатный аккаунт работает 7 дней).
Xcode: собери из исходников (см. ниже) и запусти на своём iPhone.
Сборка из исходников
iOS (ios/)
Нужны Xcode 16+ и XcodeGen.

cd ios
xcodegen generate
open OrbitPay.xcodeproj
Для запуска на устройстве укажи свою команду (Team) в Signing & Capabilities.

Android (android/)
Нужны JDK 17+ и Android SDK (platform 35). Проще всего открыть папку android/ в Android Studio. Из консоли:

cd android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
Стек
iOS: Swift, SwiftUI, Core Image (генерация QR)
Android: Kotlin, Jetpack Compose, ZXing (генерация QR)
Ответственное использование
Приложение сделано для розыгрышей среди друзей. Не используй его, чтобы вводить людей в заблуждение: например, показывать продавцу «оплату» вместо настоящей. Надпись «пранк-терминал, не настоящий» и пометка в финале — часть приложения, не убирай их при форках и распространении.
